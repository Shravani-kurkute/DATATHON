# 🛒 SmartCart – E-Commerce Analytics & Recommendation System

SmartCart is a 📊 data-driven e-commerce web application designed to analyze customer behavior, provide 🔮 product recommendations, and generate predictive insights for an online shopping platform. The project integrates 🌐 frontend web pages with a 🐍 Python-based backend and analytics modules.

---

## 📌 Project Overview

SmartCart simulates a 🧠 smart e-commerce platform where users can browse products 🛍️, manage carts 🛒, view dashboards 📈, and receive personalized recommendations 🎯. It demonstrates the practical use of web development and data analytics in modern retail systems.

---

## 🚀 Features

- 👤 User signup and profile management  
- 🛍️ Product browsing across multiple categories  
  - 📱 Electronics  
  - 👕 Clothing  
  - 👟 Footwear  
  - 🏡 Home Decor  
  - ⌚ Watches, 👞 Shoes, 👕 T-Shirts  
- 🔍 Product filtering and availability checks  
- 💳 Cart and payment workflow  
- 📊 Customer analytics dashboard  
- 🔮 Product prediction and recommendation module  
- 📓 Data analysis using Jupyter Notebook  

---

## 🧠 Tech Stack

- 🌐 Frontend: HTML, CSS  
- 🐍 Backend: Python (Flask-based)  
- 📓 Analytics: Jupyter Notebook  
- 📊 Visualization: Power BI concepts  
- 🛠️ Tools: Python 3.x, Web Browser

## ⚙️ Installation & Setup

1️⃣ Clone the repository  
```
git clone https://github.com/your-username/SmartCart.git
cd SmartCart
```

2️⃣ Install dependencies  
```
pip install flask
```

---

## ▶️ How to Run the Project

1️⃣ Navigate to backend folder  
```
cd Datathon
```

2️⃣ Run the application  
```
python app.py
```
or  
```
python app2.py
```

3️⃣ Open in browser 🌍  
```
http://127.0.0.1:5000/
```

(You can also open `index.html` directly for static UI preview.)
